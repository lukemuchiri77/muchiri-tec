# Muchiri.TEC Portfolio

A colorful, responsive personal technology portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page content and structure
- `styles.css` — colors, layout, responsive styling and animations
- `script.js` — mobile navigation and automatic footer year

## Run it locally

1. Download and extract the project ZIP.
2. Open the `muchiri-tec` folder in Visual Studio Code.
3. Open `index.html` in your browser.

Optional: install the **Live Server** extension in VS Code, right-click `index.html`, and choose **Open with Live Server**. This refreshes the browser when you save changes.

No build tools or package installation are required.

## Personalize before publishing

1. In `index.html`, update the About section so it accurately describes your background and experience.
2. Replace `hello@example.com` in the contact link with a professional email address you use.
3. Replace the three starter project ideas with real projects. Add a short description, technologies used, screenshots, and working demo or repository links.
4. Update the skill tags to match tools you can confidently use.
5. Add links to your GitHub and other professional profiles when ready.

The project cards are clearly marked as ideas/placeholders. Do not present them as completed work until you have built them.

## Publish with GitHub Pages

1. Create a GitHub account and a new repository, for example `muchiri-tec`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The Pages screen will show the live URL.

## Notes

- Google Fonts are loaded online. The site still works with fallback fonts if they cannot load.
- The email link opens the visitor's default email application; it is not a server-backed contact form.
- Check the site on both a phone and a desktop before sharing it.
